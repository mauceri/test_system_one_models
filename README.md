# test_system_one_models

Bac à sable pour tester des modèles, un répertoire par modèle testé.

## Contenu

- `test-jed/` — premier modèle testé : **Jed**.

## Principe

Chaque modèle dispose de son propre répertoire, autonome : protocole de test,
entrées, sorties attendues, résultats observés. Aucun code n'est partagé entre
les répertoires à ce stade.

Ajouter un modèle = ajouter un répertoire (par exemple `test-<modele>/`).

## Statut

Dépôt initialisé. Aucun test exécuté pour l'instant.
